
# Fluid Rotation & Angular Deformation Visualizer

An interactive 3D visualization I built to better understand how a fluid element behaves under rotation and angular deformation.

The idea was to go beyond textbook diagrams and actually see how a fluid element changes its orientation and shape with time.

## What's Inside?

- **Pure Rotation:** The element rotates without changing its shape.
- **Angular Deformation:** The element changes shape without undergoing rigid-body rotation.
- **Combined Motion:** Visualizes rotation and deformation together.

## Features

- Switch between 2D and 3D views.
- Explore motion in the XY, YZ, and ZX planes.
- Adjust rotation rate, shear rate, and direction.
- Play, pause, or step through the animation.
- Track angular changes and velocity vectors in real time.
- Explore velocity-gradient decomposition: **L = D + W**.

## Built With

- HTML
- CSS
- JavaScript
- Three.js

## How to Run

1. Download `FluidRotation.html`.
2. Open the file in your browser.
3. Experiment with different parameters and observe the changes.

No installation required, just an internet connection to load Three.js.

Fluid element: rotation vs. angular deformation


Live angles (finite time)

Velocity-gradient decomposition (case C)

What you are seeing

A · Rigid rotation. Velocity u = Ω × x. Every point circles the centre at the same angular rate; edge lengths and the 90° corners never change. Both edges turn the same way: Δα = −Δβ, so ½(Δα−Δβ) grows but Δα+Δβ = 0.

B · Pure angular deformation. Velocity u = D x with symmetric D (Dxy = γ̇/2). The edges tilt toward each other (Δα = Δβ), the 90° corner closes, and the cube becomes a parallelepiped with zero net spin. The finite map is exp(tD), so edges also stretch.

C · Combined. Velocity u = (D + W) x = L x. At t = 0 the velocity field is exactly the sum of A's and B's. The element rotates and deforms because L has both a symmetric and an antisymmetric part. With linking on, C is the simple shear u = γ̇y, whose spin is ωz = −γ̇/2 (clockwise) and Dxy = γ̇/2.

Instantaneous vs finite: L = D + W is exact for velocities at one instant. For finite time the map is F = exp(tL), and in general exp(t(D+W)) ≠ exp(tD)·exp(tW). Here C is built directly from A and B: FC = FA·FB (B's stretch first, then A's rigid rotation). That is a polar decomposition F = R·U, so C is always A's rotation applied to B's deformed shape.
